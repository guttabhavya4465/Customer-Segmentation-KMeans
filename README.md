# Customer Segmentation using K-Means

## Project Overview
This project uses the K-Means clustering algorithm to segment customers based on their behavior.
The dataset contains customer details like:
- Age
- Annual Income
- Spending Score
The goal is to group customers into different clusters for better business understanding.
##  Dataset
Dataset used: Mall_Customers.csv
Features used:
- Annual Income (k$)
- Spending Score (1-100)
## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
##  Steps Performed
1. Imported dataset
2. Selected important features
3. Used Elbow Method to find optimal clusters
4. Applied K-Means clustering
5. Visualized clusters using scatter plot
## Output
- Customer groups are formed based on spending behavior
- Graph shows different clusters with centroids
